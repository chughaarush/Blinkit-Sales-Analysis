# 🛒 Blinkit Sales Analysis

## 📌 Project Overview

This project analyzes Blinkit's retail sales dataset using Python, SQL, and Power BI. The objective is to clean the data, perform exploratory data analysis (EDA), extract business insights using SQL, and build an interactive dashboard for visualization.

---

## 📊 Dataset

- Dataset: Blinkit Sales Dataset
- Records: ~8,500
- Source: Kaggle

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL (MySQL)
- Power BI
- Excel

---

## 📂 Project Workflow

1. Data Cleaning using Python
2. Exploratory Data Analysis (EDA)
3. SQL Business Queries
4. Power BI Dashboard Creation

---

## 📈 Dashboard Features

- Total Sales KPI
- Average Sales KPI
- Total Items KPI
- Average Rating KPI
- Sales by Item Type
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Outlet Establishment Year
- Sales by Item Fat Content
- Interactive Filters (Slicers)

---

## 🔍 Key Insights

- Medium-sized outlets generated the highest sales.
- Regular fat products contributed more revenue than low-fat products.
- Fruits & Vegetables and Snack Foods were among the highest-selling categories.
- Tier 3 outlets generated the highest overall sales.
- Sales varied across outlet establishment years, indicating differences in outlet performance.
